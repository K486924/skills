# Antigravity Skills

Reusable agent skills for building optimized Blender assets and Roblox environments.

## Included skills

- **[blender-roblox-assets](blender-roblox-assets/SKILL.md)** — Blender modeling standards, low-poly optimization, pivots, materials, and Roblox export workflow.
- **[roblox-world-builder](roblox-world-builder/SKILL.md)** — Roblox Studio environment organization, map design, performance, safe scripting, and testing.

## Install in an Antigravity project

Copy the skill folders into your project so the structure looks like this:

```text
.agent/
  skills/
    blender-roblox-assets/
      SKILL.md
    roblox-world-builder/
      SKILL.md
```

Then open the project in Antigravity and ask it to use the relevant skill when creating Blender assets or editing the Roblox place.

## Focus

These skills are designed for modular, stylized, low-poly assets and lightweight Roblox experiences, including a food-throwing dog-park simulator.
